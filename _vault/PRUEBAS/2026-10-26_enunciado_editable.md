# Prueba 004 · Páginas del enunciado sueltas y salida solo con la flecha (pendiente)

**Qué cambia ([ADR-017](../CONSTRUCCION/DECISIONES.md)):**
- lo pegado en el enunciado se mueve, se redimensiona y se quita con el dedo;
- de la hoja solo se sale con la flecha «Inicio».

**Requisito:** CI en verde y el zip `ultima` instalado con el Atajo. Si queda pendiente la [prueba 003b](2026-10-26_practica_rueda_mayor.md), se puede hacer en la misma sesión.

| # | Qué hacer | Qué debería pasar | Resultado |
|---|---|---|---|
| 1 | Abrir una práctica con dos capturas o más pegadas y tocar una con el dedo | Marco azul, una bola en cada esquina y, encima, «Al ancho» y «Quitar» | |
| 2 | Arrastrar con el dedo dentro de la captura elegida | La captura se mueve con el dedo; al soltar se queda ahí y por delante de las demás | |
| 3 | Tirar de la bola de abajo a la derecha hacia dentro y luego hacia fuera | Se achica y se agranda sin deformarse; la esquina de arriba a la izquierda no se mueve | |
| 4 | Escribir con el Pencil encima de una captura, elegirla y moverla o redimensionarla | Lo escrito va con ella (se ve moverse mientras arrastras) y se escala igual | |
| 5 | Tocar fuera de la captura (o escribir con el Pencil) | El marco desaparece; con el dedo fuera de las páginas, el enunciado se desplaza como siempre | |
| 6 | Elegir una captura → «Al ancho» | Vuelve al ancho de partida, centrada, a la misma altura | |
| 7 | Elegir una captura → «Quitar» → «Quitar esta página» | Desaparece con lo escrito encima; las demás no se mueven | |
| 8 | Arrastrar la separación del panel a izquierda y derecha, y deslizar desde el borde izquierdo | No se sale al inicio | |
| 9 | Tocar «‹ Inicio» arriba a la izquierda | Vuelve al inicio y la hoja queda guardada (también en una hoja normal, no solo en una práctica) | |
